Consultar el diccionario para visualizar solo las tablas que el mismo usuario creó:

```
SELECT table_name FROM USER_TABLES;
```

Consultar el dicccionario para visualizar las tablas que el mismo usuario creó y las que otros usuarios les dieron permiso:
  
```
SELECT owner, table_name FROM ALL_TABLES;
```

Devolver un listado de las tablas, en qué tablespace vive cada una, y una estimación de cuántas filas tiene cada una:

```
SELECT table_name, tablespace_name, num_rows
FROM USER_TABLES;
```

Ver las columnas de la tabla employees:

```
SELECT column_name, data_type, data_length, nullable
FROM USER_TAB_COLUMNS WHERE table_name = 'EMPLOYEES';
```

Ver las  restricciones (constraints) de la tabla EMPLOYEES:

```
SELECT constraint_name, constraint_type, status
FROM USER_CONSTRAINTS WHERE table_name = 'EMPLOYEES';
```

Ver los índices de la tabla EMPLOYEES:

```
SELECT index_name, uniqueness
FROM USER_INDEXES WHERE table_name = 'EMPLOYEES';
```

Buscar el campo name en todas las tablas:

```
SELECT table_name, column_name, data_type FROM user_tab_columns WHERE column_name LIKE '%NAME%';
```

Buscar todos los Triggers:

```
SELECT * FROM user_objects WHERE object_type='TRIGGER';
```

Realizar una consulta que liste **todos los objetos del esquema actual que fueron creados o modificados hoy**:

```
SELECT object_type, object_name, last_ddl_time FROM user_objects WHERE last_ddl_time >= TRUNC (SYSDATE) ORDER BY object_type, object_name;
```
