Se solicita una procedimiento denominado show_info_employees que muestre información del empleado pasado por parámetro usando CURSORES IMPLICITOS:

```
CREATE or REPLACE PROCEDURE show_info_employees(p_id employees.employee_id%TYPE) IS
v_name  employees.first_name%TYPE;
v_last_name  employees.last_name%TYPE;
v_salary employees.salary%TYPE;
BEGIN
    SELECT first_name, last_name, salary INTO v_name,v_last_name,v_salary
    FROM   employees
    WHERE  employee_id = p_id;
    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Encontrado: ' || v_name || CHR(9) || v_last_name ||   
        CHR(9) || to_char(v_salary));
    END IF;
    DBMS_OUTPUT.PUT_LINE('Filas encontradas: ' || SQL%ROWCOUNT);
    EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('El empleado no fue encontrado.');
END;

```

Crear un procedimiento denominado transfer_employee que transfiere un empleado a otro departamento, actualizando también su jefe automáticamente usando CURSORES IMPLICITOS.
Si ocurre un error  se hace `ROLLBACK` para deshacer cualquier cambio parcial.

```
CREATE OR REPLACE PROCEDURE transfer_employee(
    p_emp_id       IN employees.employee_id%TYPE,
    p_new_dept_id  IN employees.department_id%TYPE
) IS
BEGIN
    UPDATE employees
    SET    department_id = p_new_dept_id,
           manager_id    = (SELECT manager_id
                            FROM   departments
                            WHERE  department_id = p_new_dept_id)
    WHERE  employee_id = p_emp_id;

    IF SQL%NOTFOUND THEN
        RAISE_APPLICATION_ERROR(-20001,
            'El empleado ' || p_emp_id || ' no existe.');
    END IF;

    DBMS_OUTPUT.PUT_LINE(
        'Empleado ' || p_emp_id ||
        ' se transfiero al departamento ' || p_new_dept_id ||
        '. Filas actualizada: ' || SQL%ROWCOUNT
    );

    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
END transfer_employee;
```

Realizar un procedimiento de PL/SQL usando CURSORES EXPLICITOS que busca todos los empleados pertenecientes a un departamento pasado por parámetro y muestra los nombres completos junto con su salario, ordenados de mayor a menor sueldo :

```
CREATE or REPLACE PROCEDURE show_dept_salary(p_id employees.department_id%TYPE) IS
v_emp_id    employees.employee_id%TYPE;
v_fname     employees.first_name%TYPE;
v_lname     employees.last_name%TYPE;
v_salary    employees.salary%TYPE;
CURSOR c_dept_employees IS
        SELECT employee_id, first_name, last_name, salary
        FROM   employees
        WHERE  department_id = p_id
        ORDER BY salary DESC;
BEGIN
    OPEN c_dept_employees;
    LOOP
        FETCH c_dept_employees INTO v_emp_id, v_fname, v_lname, v_salary;
        EXIT WHEN c_dept_employees%NOTFOUND;  

        DBMS_OUTPUT.PUT_LINE(
            v_fname || ' ' || v_lname || ': ' || v_salary || '$'
        );
    END LOOP;
    CLOSE c_dept_employees;
END;
```

El departamento de Ventas (department_id = 80) va a recibir un bono fijo de $800 para todos sus empleados. Desarrollar un procedure `sp_bonus_sales` que traiga con `BULK COLLECT` los `employee_id` de todos los empleados del departamento 80, usando una colección  y con `FORALL`, sume $800 al salario de cada uno. Informando al finalizar cuántas filas fueron actualizadas.

```
CREATE OR REPLACE PROCEDURE sp_bonus_sales IS

    TYPE t_id_list IS TABLE OF employees.employee_id%TYPE;
    v_ids t_id_list;

BEGIN
 
    SELECT employee_id
    BULK COLLECT INTO v_ids
    FROM employees
    WHERE department_id = 80;

    IF v_ids.COUNT = 0 THEN
        DBMS_OUTPUT.PUT_LINE('No hay empleados en el departamento 80.');
        RETURN;
    END IF;
 
    FORALL i IN 1..v_ids.COUNT
        UPDATE employees
        SET    salary = salary + 200
        WHERE  employee_id = v_ids(i);

    DBMS_OUTPUT.PUT_LINE('Filas actualizadas: ' || SQL%ROWCOUNT);
    COMMIT;
END ;
```

Realizar un procedimiento PL/SQL para aplicar un **aumento salarial del 10%** a los empleados de un departamento determinado mediante **procesamiento en lote (Bulk Processing)** para optimizar el rendimiento.

```
CREATE or REPLACE PROCEDURE update_collect_salary(p_id employees.department_id%TYPE) IS
    TYPE t_id_list  IS TABLE OF employees.employee_id%TYPE;
    TYPE t_sal_list IS TABLE OF employees.salary%TYPE;
    v_ids    t_id_list;
    v_sals   t_sal_list;
BEGIN
    SELECT employee_id, salary * 1.10
    BULK COLLECT INTO v_ids, v_sals
    FROM   employees
    WHERE  department_id = p_id;
    IF v_ids.COUNT > 0 THEN
        FORALL i IN 1..v_ids.COUNT
            UPDATE employees
            SET    salary = v_sals(i)
            WHERE  employee_id = v_ids(i);
        DBMS_OUTPUT.PUT_LINE('Updated ' || SQL%ROWCOUNT || ' rows.');
    ELSE
        DBMS_OUTPUT.PUT_LINE('No employees found for department ' || p_id);
    END IF;
    COMMIT;
END;
```
