# CLASE DEL 10-09-26 y 15-09-26

Iniciar una sesión de la terminal bash desde docker:

```
docker exec -it oracle-db bash
```

Lanzar la línea de comando sqlplus con el usuario system:

```
sqlplus system/maria123456@localhost:1521
```

Desplegar el usuario actual en la línea de comando:

```
show user;
```

Mostrar el contenedor donde esta conectado:

```
show con_name;
```

Pasarse al PDB denominado freepdb1:

```
alter session set container=freepdb1
```

Crear el usuario BOB desde la cuenta SYSTEM:

```
CREATE USER bob IDENTIFIED BY Superpassword;
```

Asígnele el permiso para poder conectarse:

```
GRANT CREATE SESSION TO bob;
```

Desde la cuenta SYSTEM conectese como usuario BOB:

```
CONN bob/Superpassword@localhost:1521/FREEPDB1;
```

Desde otra terminal acceda al usuario SYSTEM con los siguientes comandos:

```
docker exec -it oracle-db bash
sqlplus system/maria123456@localhost:1521
```

Otórgueles el permiso de creación de tablas a BOB:

```
GRANT CREATE TABLE TO bob;
```

Ahora desde la conexión de BOB cree una tabla de ejemplo:

```
CREATE TABLE test (
 id NUMBER
);
```

Desde SYSTEM asígnele una CUOTA de espacio del tablespace a BOB:

```
GRANT UNLIMITED TABLESPACE TO bob;
```

Desde BOB haga una inserción de prueba:

```
INSERT INTO test VALUES(1);
```

Desde SYSTEM  quítele el privilegio de creación de tablas a BOB:

```
REVOKE CREATE TABLE FROM bob;
```

Desde SYSTEM cree el usuario ALEX con la contraseña alex123456, otórgueles el permiso de conexión y asígnele una cuenta de 100 Mb de espacio sobre el tablespace USERS:

```
CREATE USER alex IDENTIFIED BY alex123456;
GRANT CREATE SESSION TO alex;
ALTER USER alex QUOTA 100M ON USERS;
```

Asígnele los privilegios SELECT, INSERT, UPDATE y DELETE sobre el objeto EMPLOYEES del esquema HR  al usuario ALEX:

```
GRANT SELECT, INSERT, UPDATE, DELETE ON hr.emp TO alex;
```

Sobre el usuario BOB verificar los privilegios otorgados por el usuario SYSTEM:

```
SELECT * FROM USER_TAB_PRIVS;
```

Desde BOB escriba el siguiente comando para listar todos los empleados de la organización:

```
SELECT COUNT(*) FROM hr.employees;
```

Modifique la contraseña desde SYSTEM del usuario ALEX por la nueva contraseña Superpassword123456:

```
ALTER USER dev_app IDENTIFIED BY Superpassword123456;
```

Desde  el usuario SYSTEM indique al usuario ALEX que la próxima vez que inicie sesión modifique la contraseña

```
ALTER USER alex PASSWORD EXPIRE;
```

Luego ingrese desde ALEX y modifique la contraseña. Ahora desde SYSTEM bloque el usuario ALEX:

```
ALTER USER alex ACCOUNT LOCK;
```

Cuando ALEX inicie sesión estará bloqueado sin poder conectarse. Desde SYSTEM desbloquee al usuario ALEX:

```
ALTER USER alex ACCOUNT UNLOCK;
```
