Realizar un procedimiento PL/SQL para aplicar un **aumento salarial del 10%** a los empleados de un departamento determinado mediante **procesamiento en lote (Bulk Processing)** para optimizar el rendimiento.

```
CREATE or REPLACE PROCEDURE update_collect_salary(p_id employees.department_id%TYPE) IS
    TYPE t_id_list  IS TABLE OF employees.employee_id%TYPE;
    TYPE t_sal_list IS TABLE OF employees.salary%TYPE;
    v_ids    t_id_list;
    v_sals   t_sal_list;
BEGIN
    SELECT employee_id, salary * 1.10
    BULK COLLECT INTO v_ids, v_sals
    FROM   employees
    WHERE  department_id = p_id;
    IF v_ids.COUNT > 0 THEN
        FORALL i IN 1..v_ids.COUNT
            UPDATE employees
            SET    salary = v_sals(i)
            WHERE  employee_id = v_ids(i);
        DBMS_OUTPUT.PUT_LINE('Updated ' || SQL%ROWCOUNT || ' rows.');
    ELSE
        DBMS_OUTPUT.PUT_LINE('No employees found for department ' || p_id);
    END IF;
    COMMIT;
END;
```

Crear un trigger llamado `salary_validation` que se ejecute **antes** de las operaciones de **INSERT** o **UPDATE** sobre la tabla `employees`. El trigger debe validar que el valor del campo `salary` del nuevo registro  sea mayor que cero. 

```
CREATE OR REPLACE TRIGGER salary_validation
BEFORE INSERT OR UPDATE on employees
FOR EACH ROW
BEGIN 
		IF :NEW.salary <= 0 THEN 
			RAISE_APPLICATION_ERROR(-20001, 'El salario debe ser mayor que cero');
		END IF;
END;

```

Crear un trigger denominado print_salary_changes que se disparará antes de que se realice un UPDATE.  El mismo informará el valor del salario antes y luego de actualizarlo .

```
CREATE OR REPLACE TRIGGER print_salary_changes
BEFORE UPDATE ON employees
FOR EACH ROW 
WHEN (new.employee_id > 0) 
DECLARE 
    sal_diff number; 
BEGIN 
  sal_diff := :new.salary - :old.salary; 
  dbms_output.put_line('Old salary: ' || :old.salary);   
  dbms_output.put_line('New salary: ' || :new.salary);
  dbms_output.put_line('Difference ' || sal_diff);
END;

```
