Se solicita desarrollar un procedimiento almacenado en PL/SQL llamado `get_eligible_promotion` que cumpla con los siguientes requerimientos:

**Parámetros de entrada:**

1. `p_employee_id` (NUMBER): identificador del empleado a evaluar.
2. `p_reference_date` (DATE): fecha respecto de la cual se desea calcular la antigüedad del empleado. Este parámetro debe ser **opcional**; en caso de no especificarse, el procedimiento debe tomar por defecto la fecha actual del sistema (`SYSDATE`).

**Lógica de negocio:**

1. El procedimiento debe consultar la tabla `employees` y obtener la **fecha de contratación** (`hire_date`) y el **salario** (`salary`) del empleado indicado por `p_employee_id`.
2. Se debe calcular la **cantidad de años trabajados** por el empleado, considerando la diferencia entre `p_reference_date` y `hire_date`, expresada en años completos (redondeada).
3. Un empleado es **elegible para promoción** (`'SI'`) si su antigüedad, calculada respecto a la fecha de referencia, es **mayor a 10 años**. Caso contrario, no es elegible (`'NO'`).

```
CREATE OR REPLACE PROCEDURE get_eligible_promotion (
    p_employee_id      IN NUMBER,
    p_reference_date   IN DATE DEFAULT SYSDATE
) IS

    v_salary             employees.salary%TYPE;
    v_hire_date          employees.hire_date%TYPE;
    v_years_worked       NUMBER(2);
    v_eligible_promotion CHAR(2);
BEGIN
    SELECT
        hire_date,
        salary
    INTO
        v_hire_date,
        v_salary
    FROM
        employees
    WHERE
        employee_id = p_employee_id;

    v_years_worked := round(months_between(p_reference_date, v_hire_date) / 12);
    IF v_years_worked > 10 THEN
        v_eligible_promotion := 'SI';
    ELSE
        v_eligible_promotion := 'NO';
    END IF;

    dbms_output.put_line('=== EVALUACIÓN DE RENDIMIENTO ===');
    dbms_output.put_line('Empleado ID: ' || p_employee_id);
    dbms_output.put_line('Fecha de referencia: ' || TO_CHAR(p_reference_date,   
    'DD/MM/YYYY'));
    dbms_output.put_line('Años trabajados: ' || v_years_worked);
    dbms_output.put_line('Promociona: ' || v_eligible_promotion);
END get_eligible_promotion;
```

Ejecutar el procedimiento almacenado:

1° FORMA:

```
-- Ejecutando la fecha por defecto
BEGIN
    get_eligible_promotion(101);
END;

```

2° FORMA:

```
-- Evaluando una fecha
BEGIN
    get_eligible_promotion(101, TO_DATE('01/01/2030', 'DD/MM/YYYY'));
END;
```

Se necesita conocer cuántos empleados fueron contratados dentro de un determinado período de años. Para esto, se solicita desarrollar un procedimiento almacenado en PL/SQL llamado `get_hired_employees` que cumpla con los siguientes requerimientos:

**Parámetros de entrada:**

1. `p_start_year` (NUMBER): año de inicio del periodo a evaluar.
2. `p_end_year` (NUMBER): año final del periodo a evaluar.

**Lógica de negocio:**

1. El procedimiento debe validar que el año de inicio (`p_start_year`) sea **estrictamente menor** que el año de fin (`p_end_year`).
    - Si la validación es correcta, debe consultar la tabla `employees` y **contar la cantidad de empleados** cuya fecha de contratación (`hire_date`) tenga un año comprendido entre `p_start_year` y `p_end_year` (ambos inclusive).
    - Si la validación **no** se cumple (es decir, el año de inicio es mayor o igual al año de fin), el procedimiento no debe realizar ninguna consulta y en su lugar debe informar el error correspondiente.

```
CREATE OR REPLACE PROCEDURE get_hired_employees (
    p_start_year IN NUMBER,
    p_end_year   IN NUMBER
) IS
    v_count NUMBER;
BEGIN
    IF p_start_year < p_end_year THEN
        SELECT
            COUNT(*)
        INTO v_count
        FROM
            employees
        WHERE
            EXTRACT(YEAR FROM hire_date) BETWEEN p_start_year AND p_end_year;

        dbms_output.put_line(v_count);
    ELSE
        dbms_output.put_line('El primer año debe ser menor que el segundo año');
    END IF;
END;
```

Ejecutar el procedimiento almacenado anterior:

```
BEGIN
 get_hired_employees(2015,2018);
END;
```
