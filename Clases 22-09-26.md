# CLASE DEL 22-09-26

Iniciar una sesión de la terminal BASH desde docker:

```
docker exec -it oracle-db bash
```

Crear un directorio de trabajo para almacenar el backup:

```
mkdir -p /opt/oracle/backups
```

Indicar  quién es el propietario del directorio backups (en este caso el usuario oracle) y cuál es su grupo propietario (oinstall):

```
chown oracle:oinstall /opt/oracle/backups
```

Modificar los permisos de acceso al directorio backups:

```
chmod 770 /opt/oracle/backups
```

Desde otra ventana de la terminal acceder como usuario SYSTEM a SQL PLUS:

```
sqlplus system/maria123456@localhost:1521/freepdb1
```

Desde la línea de comandos SQL cree un directorio logico para SQL:

```
CREATE OR REPLACE DIRECTORY backup_2026 AS '/opt/oracle/backups';
```

Modifique los permisos de lectura y escritura al directorio creado:

```
GRANT READ, WRITE ON DIRECTORY backup_2026 TO hr;
```

Verifique la creación de dicho directorio a través del comando:

```
SELECT * FROM dba_directories;
```

Ahora vuelva a la terminal BASH y ejecute el comando de exportación lógica Oracle Data Pump Export

```
expdp hr/pwdOracle123456@localhost:1521/freepdb1 schemas=hr directory=backup_2026 dumpfile=data_back.dump logfile=data_back.log
```

En resumen el comando realiza lo siguiente:

|                            |                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `hr/pwdOracle123456`       | Se conecta como el usuario **HR** utilizando esa contraseña                                                              |
| `@localhost:1521/freepdb1` | Se conecta al servicio `freepdb1` del servidor local mediante el puerto `1521`                                           |
| `schemas=hr`               | Indica que se exportará el **esquema HR**                                                                                |
| `directory=backup_2026`    | Indica el **objeto DIRECTORY de Oracle** donde se crearán los archivos                                                   |
| `dumpfile=data_back.dump`  | Nombre del archivo que contendrá los datos exportados                                                                    |
| `logfile=data_back.log`    | Archivo donde se registrará información sobre objetos procesados, errores, advertencias y el resultado final del trabajo |
