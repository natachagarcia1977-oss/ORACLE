Identificar cuales son los department_id  de la tabla employees y colocarlos en filas :

```
SELECT DISTINCT department_id FROM employees ORDER BY department_id;
```

Mostrar los department_id en una solo fila separados por comas:

```
SELECT LISTAGG(DISTINCT department_id, ',')
       WITHIN GROUP (ORDER BY department_id)
FROM employees;
```

Ahora queremos saber cuántos empleados hay en los departamentos (10,20,30,50):

```
SELECT *
FROM (
    SELECT department_id
    FROM employees
)
PIVOT (
    COUNT(*) 
    FOR department_id IN (
        10 AS "Administración",
        20 AS "Marketing",
        30 AS "Compras",
        50 AS "Depósito"
    )
);
```


Ahora queremos visualizar los promedios salarial redondeados con dos decimales:

```

SELECT
    ROUND(Dept_10,2) AS Dept_10,
    ROUND(Dept_20,2) AS Dept_20,
    ROUND(Dept_30,2) AS Dept_30,
    ROUND(Dept_50,2) AS Dept_50
FROM (
    SELECT *
    FROM (
        SELECT department_id, salary
        FROM employees
    )
    PIVOT (
        AVG(salary)
        FOR department_id IN (
            10 AS Dept_10,
            20 AS Dept_20,
            30 AS Dept_30,
            50 AS Dept_50
        )
    )
);
```

Utilizar PIVOT para convertir los valores de `department_id` en columnas mientras mantiene job_id como filas. 

```

SELECT *
FROM (
    SELECT job_id, department_id
    FROM employees
)
PIVOT (
    COUNT(*)
    FOR department_id IN (
        10 AS Dept_10,
        20 AS Dept_20,
        30 AS Dept_30,
        50 AS Dept_50
    )
)
ORDER BY job_id;
```

Cuántos empleados se contrataron en los años 2014,2015 y 2016 en los departamentos 30, 50 y 80.

```
SELECT * FROM (
    SELECT department_id, EXTRACT(YEAR FROM hire_date) AS anio_contratacion
    FROM employees
    WHERE department_id IN (30, 50, 80)
)
PIVOT (
    
    COUNT(*) 
    FOR anio_contratacion IN (2014 AS contratados_2014, 
                              2015 AS contratados_2015, 
                              2016 AS contratados_2016)
);
```
