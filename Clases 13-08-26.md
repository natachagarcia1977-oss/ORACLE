Se solicita una función denominada get_count_employees que indique cuántos empleados fueron contratados dentro de un rango de año determinado. Si `p_start_year` es menor que `p_end_year` debe devolver la cantidad de empleados entre esos dos años. Si `p_start_year` es mayor que `p_end_year` la función debe retornar `-1` como código de error.

```
CREATE OR REPLACE FUNCTION get_count_employees(
    p_start_year IN NUMBER,
    p_end_year   IN NUMBER
) RETURN NUMBER IS
    v_count NUMBER;
BEGIN
    IF p_start_year < p_end_year THEN
        SELECT
            COUNT(*)
        INTO v_count
        FROM
            employees
        WHERE
            EXTRACT(YEAR FROM hire_date) BETWEEN p_start_year AND p_end_year;
        RETURN v_count;
    ELSE
        RETURN -1;
    END IF;
END;
```

Se pide agregar el manejo de excepciones al procedimiento denominado `get_hired_employees`.El procedimiento debe validar que el año de inicio (`p_start_year`) sea **estrictamente menor** que el año de fin (`p_end_year`).Esta validación debe implementarse mediante el **manejo estructurado de excepciones** de PL/SQL

```
CREATE OR REPLACE PROCEDURE get_hired_employees (
    p_start_year IN NUMBER,
    p_end_year   IN NUMBER
) IS
    v_count           NUMBER;
    e_invalid_range   EXCEPTION;
BEGIN
    IF p_start_year >= p_end_year THEN
        RAISE e_invalid_range;
    END IF;

    SELECT
        COUNT(*)
    INTO v_count
    FROM
        employees
    WHERE
        EXTRACT(YEAR FROM hire_date) BETWEEN p_start_year AND p_end_year;

    dbms_output.put_line(v_count);

EXCEPTION
    WHEN e_invalid_range THEN
        dbms_output.put_line('El primer año debe ser menor que el segundo año');
END get_hired_employees;

```

Realizar una nueva versión del procedimiento `get_hired_employees`, esta vez tratando como un caso especial, cuando `v_count = 0` lanzando una nueva excepción.

```
CREATE OR REPLACE PROCEDURE get_hired_employees (
    p_start_year IN NUMBER,
    p_end_year   IN NUMBER
) IS
    v_count           NUMBER;
    e_invalid_range   EXCEPTION;
    e_no_employees    EXCEPTION;
BEGIN
    IF p_start_year >= p_end_year THEN
        RAISE e_invalid_range;
    END IF;

    SELECT
        COUNT(*)
    INTO v_count
    FROM
        employees
    WHERE
        EXTRACT(YEAR FROM hire_date) BETWEEN p_start_year AND p_end_year;

    IF v_count = 0 THEN
        RAISE e_no_employees;
    END IF;

    dbms_output.put_line(v_count);

EXCEPTION
    WHEN e_invalid_range THEN
        dbms_output.put_line('El primer año debe ser menor que el segundo año');
    WHEN e_no_employees THEN
        dbms_output.put_line('No se encontraron empleados contratados en ese rango de años');
END get_hired_employees;
```


Se requiere crear un **procedimiento almacenado** en PL/SQL llamado `show_employee_salaries` que permita consultar el salario de los empleados dentro de un rango definido (desde el 100 hasta el 105) .

```
CREATE OR REPLACE PROCEDURE show_employee_salaries IS
v_salary  employees.salary%TYPE;
v_current_date VARCHAR(10);
BEGIN
SELECT to_char(sysdate, 'YYYY-mm-dd') INTO v_current_date;
DBMS_OUTPUT.PUT_LINE('La fecha de hoy es: ' || v_current_date);
FOR i in 100..105 LOOP
        SELECT
            salary
        INTO v_salary
        FROM
            employees
        WHERE
            employee_id = i;
        DBMS_OUTPUT.PUT_LINE('El empleado  '|| i || ' tiene el siguiente salario  '|| v_salary );
END LOOP;
END show_employee_salaries;
```
