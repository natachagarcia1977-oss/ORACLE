Visualizar el clásico Hola Mundo en PL/SQL:

```
BEGIN 
    dbms_output.put_line('Hola mundo!'); 
END;
``` 

Visualizar el texto Estoy aprendiendo SQL almacenada en una variable denominada v_text:

```
DECLARE 
    v_text VARCHAR2(50) := 'Estoy aprendiendo SQL'; 
BEGIN 
    dbms_output.put_line(v_text); 
END;
```
 
Concatenar dos variables y mostrar el resultado:

```
DECLARE
    v_text     VARCHAR2(50) := 'learning sql';
    v_new_text VARCHAR2(50) := ' y tambien plsql';
    v_final    VARCHAR2(100);
BEGIN
    v_final := v_text || v_new_text;
    dbms_output.put_line(v_final);
END;
```

 Ejecutar una instrucción SELECT para devolver el nombre del empleado 120 y mostrarlo por pantalla:

```
DECLARE
    v_fname VARCHAR2(60);
BEGIN
    SELECT
        first_name
    INTO v_fname
    FROM
        employees
    WHERE
        employee_id = 120;

    dbms_output.put_line(v_fname);
END;
```
